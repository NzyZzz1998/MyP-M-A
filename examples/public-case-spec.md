# MyP-M-A 公开案例准入规范

公开案例用于展示一条可复核的产品决策链，不是聊天流水账、营销精选或私有项目备份。案例进入公开索引前必须同时通过授权、匿名化、证据追踪、版本身份和人工复核；任何一项未知都保持非公开。

## 四条治理合同

1. `contract:public-case-authorization`：只有自有、明确授权可再分发或完全合成的材料可进入候选；“网上可见”“用户发过来”不等于有再分发权。
2. `contract:public-case-anonymization`：公开物不得包含真实姓名、账号、邮箱、电话、绝对路径、设备标识、内网地址、凭据、私有仓库和可反推身份的组合信息。
3. `contract:public-case-evidence-traceability`：每个承重结论绑定公开 artifact、定位信息和 `confirmed/inferred/unknown` 状态；脱敏不得切断证据链。
4. `contract:public-case-withdrawal`：撤回后立即从公开索引移除，保留最小审计记录与 ID，不继续分发正文，不复用案例 ID。

## 准入流程

1. **登记来源**：写明 `synthetic`、`user-owned` 或 `public-licensed`，记录权利人、授权依据、时间和允许的公开范围。
2. **最小化材料**：只保留理解问题、决策、影响和结果需要的证据；删除调试流水、无关日志和第三方全文。
3. **匿名化**：先自动扫描，再人工逐文件检查；替换后仍能关联的字段使用稳定假名或案例内 ID。
4. **证据登记**：每条结论写来源 artifact、标题/段落/行号等定位和证据状态；推断不能改写为事实。
5. **版本锁定**：记录案例版本、MyP-M-A 版本、生成时间和所有公开 artifact 的 SHA-256。
6. **人工复核**：复核授权、隐私、第三方内容、事实一致性和可复核性；未关闭项阻塞公开。
7. **发布或撤回**：只有 `approved/published` 可进入 `examples/index.json`；`withdrawn` 必须从活动索引移除并填写审计。

## Manifest 最低字段

结构以 `examples/case-manifest.schema.json` 为准。Manifest 是案例身份与准入事实源，正文不得另写一套冲突状态。

## 自动扫描最低范围

- Windows、macOS、Linux 用户目录和绝对路径。
- 邮箱、手机号、内网 IPv4、账号与设备标识。
- API key、访问令牌、密码、cookie 和连接串。
- 私有仓库 URL、临时附件路径、真实用户 ID。
- artifact 缺失、SHA-256 不匹配、证据定位为空或引用越界。

自动扫描为 0 不等于可公开；语义上可反推身份、授权范围或第三方权利仍需人工判断。

## 撤回

撤回可以由权利人请求、隐私风险、授权变化、证据失真或版本淘汰触发。执行顺序：冻结分发、从活动索引移除、将 manifest 改为 `withdrawn`、记录原因与时间、保留不含敏感正文的审计。若历史发布已无法完全删除，必须记录可达位置和补救动作，不能宣称彻底移除。

## 禁止项

- 未经用户明确授权公开 QuickRec、LetsMakeMoney 或其他真实项目的日志、截图、配置与路径。
- 用合成用户、子 Agent 或 AI 总结冒充真实采用证据。
- 因展示效果删掉反例、失败项、已知限制或撤回记录。
- 将外部 Skill、文章、截图或模板全文复制进案例；只能在许可允许时短引并注明来源。
