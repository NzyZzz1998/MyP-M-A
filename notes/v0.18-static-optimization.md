# MyP-M-A v0.18 静态优化记录

## 本轮目标

先修复深度审计中已经有直接证据的问题，不把尚未运行的模型行为 eval 伪装成已验证。

## 修改前基线

- `SKILL.md` 240 行，默认要求读取判断、偏好、工具和下一阶段提示词四份 reference。
- 单次 `/idea`、`/review`、`/prd`、`/acceptance` 的基础加载量约为 53-72 KB。
- `evals/evals.json` 有 30 条用例，但使用不兼容的 `assertions` 字段，没有文件型输入和触发负例。
- 三份旧 reference 与一个旧发布模板已经被主入口替代，但仍留在运行目录。
- PRD 高保真原型门禁没有区分 UI、后端、数据库和工程治理需求。
- Review 证据状态仍使用英文，与全中文正式文档规则冲突。
- Memory 实测已经完成，但路线图仍记录为未完成。

## v0.18 已完成

- 主文件收敛为 114 行的渐进加载调度层。
- 阶段基础加载量下降约 45%-59%。
- 新增触发边界、工具能力探测、降级和外部写操作授权规则。
- PRD 使用按类型表达物，非 UI 需求不再强制生成 UI 原型。
- 新增跨阶段追踪规则与模板字段。
- 补后端数据库深度检查和压力测试置信度。
- eval schema 改为 `expectations`，用例增至 34 条，其中 4 条包含真实附件。
- 新增 10 条应触发、10 条不应触发的触发 eval。
- 新增 README、CHANGELOG 和 `scripts/validate-skill.ps1`。
