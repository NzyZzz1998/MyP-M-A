## 1. 开发范围

### 1.1 版本目标

在不新增入口、默认上下文或方法库的前提下，使 MyP-M-A 稳定保留用户与仓库已经明确的事实、范围、历史、状态和授权；同时删除无关重复，但不削弱正式 PRD、深度 Review 和 Acceptance 的承重合同。

### 1.2 本次包含

- `IDEA-001`：F1～F7 事实冻结与逐字/语义保留。
- `IDEA-002`：范围差异分类及授权门禁。
- `IDEA-003`：历史、状态、责任人与新鲜度继承。
- `IDEA-004`：N1～N4 数值来源及无依据阈值处理。
- `IDEA-005`：最小充分与内部一致性终检。
- `IDEA-006`：定向稳定性、关联任务、保护性控制和 Candidate 面板。

### 1.3 本次不包含

- `IDEA-007`：新增 PM 框架、能力卡或方法库。
- 新入口、数据库、服务、第三方插件或外部工具硬依赖。
- 改写 EB-01～EB-12 的任务语义、fixture、minimum contract 或 v0.36 结果。
- 默认执行多模型、多强度、稳定集和挑战集的穷举回归。
- 将 v0.36 的三张 `pilot` 能力卡晋级。

### 1.4 范围保护

- v0.36 运行时提交 `4bf426c` 与远端状态提交 `83e619c` 只读保留；v0.37 不改写这些提交或历史。
- 运行时规则只落在最接近决策的既有 reference；`SKILL.md` 仅在收口时更新版本元数据。
- 每个批次独立验证、独立回退，未通过不得继续扩展下一入口。
- 字符数和时长只作成本观察，不得抵消事实错误或完整性回退。
- commit、push、tag 和 Release 分别等待授权。

## 8. 风险与回退

| 风险 | 影响 | 回退/处理 |
| --- | --- | --- |
| 机械复述事实导致普通输出变长 | 用户体验下降 | 事实记录默认内部化，只展示冲突和承重事实 |
| 多个 reference 重复同一规则 | 上下文膨胀、双事实源 | 每个入口只保留本地动作，公共定义复用全局门禁 |
| 最小充分删除正式合同 | PRD/Review/Acceptance 不可用 | 回退对应压缩句，以 EB-07/09 和内部控制为硬门禁 |
| 只对 EB-08/12 过拟合 | 泛化不足 | 内部变体、关联任务、控制任务和 Candidate 面板共同约束 |
| 旧历史被永久冻结 | 状态无法推进 | 同时记录对象、新鲜度、失效条件；允许同源新证据 transition |
| v0.36 与 v0.37 混入同一提交 | 回退失效 | M0 冻结身份；v0.37 后续提交独立创建 |
| 模型/评分器不可用 | 证据不完整 | 记录无效样本，按协议最多重试一次，不替换未声明模型 |
