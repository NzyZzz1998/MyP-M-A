# v0.42 Stable 决定记录

## 决定与依据

2026-09-07，维护者在读取四模型全量结果及 R7 已知问题后，明确要求“直接进入stable”，更新 README 全量评测、注明 GPT-6 Astra 专项优化与功能范围不变；随后补充“如果5.6sol作为主力，.42也没问题”。本记录据此将版本标为 **v0.42.0 Stable**；维护者后续授权推送 test / main 及打 tag，收口提交 `79646a1` 已同步两个远端分支。

本次发布决定接受下述已知限制，原独立技术验收仍为未通过。状态迁移依据为维护者明确决定，不是新增测试通过或缺陷修复；没有修改通用运行时门禁以放行本版。

## 版本定位与推荐

| 对象 | 本版决定 |
| --- | --- |
| 功能范围 | 保留五个入口和两种交付模式，不增加产品功能；调整提示规则、事实保真及评测治理 |
| GPT-6 Astra 主力 | 推荐 v0.42，本次专项优化对象；medium 全量与 ultra 定向分别保留其证据范围 |
| GPT-5.6 Sol 主力 | 可用 v0.42，继续作为主要兼容配置；复杂语义图需要来源复核 |
| GPT-5.6 Terra / Luna 主力 | 优先保留 v0.41；本轮观察不支持各配置收益一致 |
| 其他模型 | 保留通用宿主兼容，不承诺与已测 GPT 配置同等质量 |

版本推荐是维护策略，不表示 v0.41 在所有 GPT-5.6 场景都更好，也不表示 Astra 全面领先 Sol。

## 证据与已知限制

- 四模型全量：114 条稳定用例与 46 条挑战用例，各模型 medium 一次有效结果，共 640/640 有效回答；214/214 匿名评分输入覆盖全部回答。完整分套结果见 [评测历史](evaluation-history.md#v042-full-regression-20260906)。
- R7：Astra medium 一份、Sol medium 三份均首次有效。Astra 原分 10/10；Sol 原分 9/10、9/10、10/10。独立审计确认 Sol 中的实体合并和关键关系全层遗漏，并纠正了一项被动回写方向误判。原回答和原分不改。
- **B-01：已接受风险、尚未修复。** 本次接受范围是 v0.42 的版本晋升及使用推荐；复杂语义图存在整体对象与文件节点合并、承重关系遗漏和跨层文字不一致的风险。完整交付仍需按来源核对节点、关系与摘要，已知失败不标为通过。
- 风险记录随本版保留；后续修改受影响行为时重新核验，关闭必须有绑定新快照的修复证据。本次决定不自动授权后续版本沿用豁免，也不修改用户项目的验收标准。
- 真实正式视觉包、双视口与离线读取等未覆盖项继续按 [适配记录](v0.42-adaptation-verification.md)和 R7 审计保留。有限样本不证明所有场景或模型强度稳定。
