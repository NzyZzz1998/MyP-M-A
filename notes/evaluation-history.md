# MyP-M-A 评测历史

本文是 MyP-M-A 行为评测结果的唯一长期汇总。它保留版本结论、评分口径、已知限制和下一轮基线，不保存逐次回答、评分器中间文件或静态对照网页。

## 保留范围

仓库继续保留可执行的评测基础设施：

- `evals/evals.json`：稳定集，当前 81 条。
- `evals/challenge-evals.json`：挑战集，当前 18 条。
- `evals/trigger-evals.json`：触发正反例，当前 29 条。
- `evals/files/`：自包含输入附件。
- `scripts/regression-workspace.ps1`：准备与校验隔离工作区。
- `scripts/generate-eval-viewer.ps1`：按需生成临时对照页。
- `scripts/validate-skill.ps1`：严格静态校验。

这些文件用于未来复测，不属于可清理的历史输出。

以下内容不再长期保留：

- Agent 原始回答和重试副本。
- 逐条评分 JSON、临时 benchmark 和 viewer。
- 基线与候选 Skill 快照。
- 已被最终结论替代的定向回归工作区。

## 统一判定规则

1. 稳定集与挑战集分别汇报，不混成统一质量总分。
2. 新旧版本必须使用相同模型、推理档位、输入、附件和评分标准。
3. 不按多次运行中的最高分挑选结果。
4. 执行器未落盘、超时或输出损坏单独标记，不算作 Skill 能力失败。
5. 模拟用户、合成数据和计划中的测试不能冒充真人或真实运行证据。
6. 单次全覆盖只能证明该轮没有观察到回退，不能证明低方差稳定。
7. 每轮结束后先将结果、限制和剩余缺口写入本文，再清理生成型产物。

本轮共生成并评分 198 份回答。主要增益来自：

- 3～5 条承重假设、可证伪条件、最小实验和继续/停止阈值。

### 剩余缺口

v0.28 稳定集仍有 13 个未满足检查项，分布在 12 个用例，主题包括：

- 多需求超过 2 个时的 `.md` 落盘。
- 完整交互故障分类。
- Review 接手摘要。
- 高保真原型的桌面/窄屏证据和回归。
- 失败证据继承与真人数据边界。
- Memory 实际写入确认。
- 原型模拟数据边界。
- 外部依赖部分成功的补偿策略。
- 承重假设排序。

最大代价是稳定集平均回答长度增加约 `52.8%`。v0.29 应在不删除入口、证据、授权、影响范围和停止条件的前提下治理非必要展开。
