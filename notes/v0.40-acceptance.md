## 独立审计 Findings

1. **P1：manifest 校验存在假阳性。** `scripts/test-v040-visual-delivery.ps1` 未机械重算 manifest SHA-256、确认全部产物存在或校验 viewport 明细；注入无效 manifest 后仍可零错误返回。
2. **P1：M5 真实复用未解耦。** `/review` 与 `/prd` 两套证据均使用当前 v0.40 Candidate 自身材料，未满足 `notes/dev_plan_v0.40.md` 中“与当前开发任务解耦”的要求。
3. **P1：fallback 工具状态缺少直接证据。** 模板把 `local-svg-fallback` 预填为已安装、可调用、调用成功，但当前会话没有同名工具接口或独立探针记录。
4. **P1：v0.38 回退说明不可执行。** 删除未提交改动只会回到 HEAD `1199d987...`，不会回到 v0.38 `80e6abe...`；必须区分候选工作区恢复与 Stable 快照回退。
5. **P2：release panel 路由漂移。** 11 个 delta 项中有 7 个 route 与实际 prompt 不一致。
6. **P2：状态文档陈旧。** PRD、dev plan、progress 与 README 在验收前仍写作“待动态回归 / 待独立验收”。本记录已更新事实，其他状态文件同步为“验收未通过”。

独立审计同时确认：PowerShell 7 与 Windows PowerShell 5.1 的现有脚本、`git diff --check`、JSON、PowerShell AST、UTF-8、乱码和 Markdown 链接检查均通过；两套视觉证据的现有源文件与产物哈希重算匹配，浏览器独立复放通过。这些通过项不能消除上述阻塞。
