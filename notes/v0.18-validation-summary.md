# MyP-M-A v0.18 验证总结

## 结论

MyP-M-A v0.18 已完成静态校验、代表性行为对照和三项修复后的定向 A/B 回归，可以作为当前稳定基线发布。

现有证据支持以下结论：

- 未发现相对 v0.17 的明显整体能力回退。
- `/acceptance` 的入口识别与发布阻断判断更稳定。
- 附件型 `/idea` 对反馈数、任务数、失败任务数、用户数和失败率的证据边界更清楚。
- 后端/数据库 PRD 能稳定输出规范状态契约；该项新旧版本都较强，主要作为防回退能力保留。
- 结构优化降低了默认加载量，同时没有在已执行用例中造成关键能力缺失。

本版本没有执行全部 34 个行为用例的统一三次 A/B 回归，因此不能声称 v0.18 在所有场景全面优于 v0.17。

## 静态验证

严格校验命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-skill.ps1 -Strict
```

检查范围：

- UTF-8 与常见乱码。
- SKILL、eval 和模板版本一致性。
- 34 条行为 eval 的 schema、ID 和附件路径。
- 20 条触发正反例。
- Markdown 本地引用。
- runtime reference/template 路由与孤立资源。
- `git diff --check`。

最终结果：通过。

## 行为验证

### 第一轮：10 条行为冒烟

- v0.18：76/76，100%。
- v0.17：75/76，98.6%。
- v0.18 平均输出字符数较 v0.17 少约 19.7%，未发现关键能力回退。
- 唯一明确差异是 v0.17 在 Web SaaS review 中使用英文证据状态。

### 第二轮：5 个高价值用例

覆盖：

- UI 完整 PRD 与高保真原型门禁。
- 部分通过验收与发布阻断。
- 附件型 `/idea` 数据证据。
- 后端/数据库 PRD。
- Web SaaS 项目 Review。

执行结果：29/30 个有效样本。唯一无效样本是执行器未落盘，已从能力汇总中排除。

该轮多数用例两版都表现较好，且有效样本数量不完全对称，因此不单独用于证明新版整体优于旧版；它主要暴露了入口表达、数据证据边界和状态术语三个可修正问题。

### 第三轮：三项修复的完整定向 A/B

每项新旧版本各 3 次，由同一 Luna 评分器同时评分同一用例的 6 份输出：

| 用例 | v0.18 | v0.17 |
| --- | --- | --- |
| `eval 28` 验收入口 | 8/8、8/8、7/8 | 7/8、7/8、7/8 |
| `eval 31` 数据证据 | 8/8、8/8、8/8 | 6/8、6/8、6/8 |
| `eval 32` 状态契约 | 9/9、9/9、9/9 | 9/9、9/9、9/9 |

聚合通过率：

- v0.18：98.6%。
- v0.17：87.5%。
- 定向差值：+11.1 个百分点。

该差值只代表三个定向用例，不能外推为 34 个用例的整体提升幅度。

## 真实项目证据

v0.18 规则已经在三类项目中得到实际使用：

- QuickRec：Windows 桌面录制工具，覆盖 Review、PRD、开发承接、GUI 验收和发布判断。
- LetsMakeMoney：Godot + Windows 原生桌宠，覆盖 UI 原型、配置事务、托盘/点击穿透、手动补证和版本验收。
- PCbuild：Web + MySQL + 兼容规则项目，覆盖数据库审计、原型验证型 PRD、数据治理和分层用户验证门禁。

这些真实项目证据补充了行为 eval，但不替代后续 AI/Agent、移动端和更复杂线上 SaaS 场景验证。

## 资源与遥测限制

- 现有 agent 接口没有稳定提供精确耗时和 Token 遥测。
- benchmark 中的零值代表遥测缺失，不能解释为零耗时或零 Token。
- 第二轮存在一个执行器未落盘样本，已经独立标记，不计为 skill 失败。
- 评测工作区包含大量运行产物，故意保存在 skill 仓库之外，不纳入发布提交。

## 子 Agent 运行约定

- 默认使用 `gpt-5.6-luna`。
- 5 分钟作为长尾检查点；如果 agent 明确仍正常工作则继续等待。
- 确认停滞或长期不落盘时，关闭 Luna 并使用 `gpt-5.6-terra` 重试。
- agent 完成后立即关闭，避免占用线程槽位。

## 发布判断

v0.18 可以提交并作为新的稳定基线。发布说明必须保留以下限制：

- 34 条正式 eval 已通过静态结构校验，但未全部执行统一行为 A/B。
- 当前整体结论基于代表性冒烟、高价值用例、定向回归和三个真实项目，而不是全量统计证明。
- 全量行为回归推迟到评测执行与遥测基础设施更成熟后进行。

## 后续方向

- 后续补 AI/Agent、移动端或公开 SaaS 项目验证。
