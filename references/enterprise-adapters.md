# 企业协作与数据工具适配

本文件用于把协作系统、代码托管、任务系统、文档和产品数据工具的只读结果转成 MyP-M-A 可使用的证据。它不实现连接器，也不构成新的用户入口。

## 触发与反触发

触发：当前决策必须读取外部协作对象、远端项目状态、任务/文档状态或产品数据，且本轮环境存在可探测的只读能力。

不触发：现有仓库或用户材料已经足够；用户只要求实现；调用不会改变结论；只有插件名称但没有可调用接口或目标对象。

## 最小适配信封

每次成功取证至少记录：

| 字段 | 说明 |
| --- | --- |
| `source_system` | 实际系统或工具，不写计划使用的名称 |
| `object_type/object_id` | 仓库、PR、任务、文档、指标、查询或数据集的稳定身份 |
| `captured_at` | 本轮读取时间 |
| `version_or_ref` | commit、版本、文档修订或数据版本；不存在写不适用 |
| `scope_or_filter` | 查询范围、时间窗、分支、过滤条件或样本边界 |
| `access_mode` | `read-only`；任何写入另行授权 |
| `facts` | 工具直接返回或可复算事实 |
| `unresolved_conflicts` | 与其他系统或仓库事实的差异 |
| `freshness` | 当前、过期、未知及判断依据 |
| `limitations` | 权限、分页、缺失字段、抽样、缓存或工具覆盖限制 |
| `evidence_location` | URL、文件、查询记录或结果路径 |

## 只读与授权

- 默认只读。评论、创建/修改任务、更新文档、推送代码、改仪表盘或发送消息都需要对目标和内容单独授权。
- 探测分为已安装、可调用、调用成功。只有调用成功才能写入事实；调用失败记录失败原因和降级。
- 不要求安装指定插件。存在等价能力时可替换，并报告实际工具。

## 身份与跨系统冲突

- 跨系统只按稳定 ID、明确 URL、commit/ref、外键或用户确认关系关联。
- 标题、姓名或文本相似不能自动证明是同一对象。
- 远端与本地冲突时同时保留对象、时间和差异；由用户指定事实源，或按当前任务的正式系统裁决。
- 工具摘要、缓存和搜索结果不能覆盖源对象正文。

## 产品数据证据

- 先锁定统计对象、唯一键、分母、时间窗、时区、过滤、数据截至时间和版本。
- 计算事实、评分器/分析判断和产品解释分层；不能把模型评分当成业务指标。
- 仪表盘截图只证明展示，不自动证明查询、数据新鲜度或分母正确。
- 数据不可访问时给出只读查询或导出字段清单，不声称已分析。

## 两个试点

### A. 协作项目状态

读取 GitHub 等远端仓库状态与本地 Git/状态文档，输出同一对象的 ref、时间、差异和限制。结果只进入 `/review` 或 `/acceptance` 证据清单，不自动推送或修改远端。

### B. 产品指标或评测数据

读取结构化 JSON/CSV/数据库结果，复算分维指标并记录统计口径。结果进入 `/idea`、`/review` 或 `/acceptance`；不同维度分开报告，不合并为统一总分。

## 降级与停止

- 工具不可用：使用用户提供导出或本地事实，缺失部分标待验证。
- 权限不足、分页不完整、对象身份冲突或数据过期：停止形成确认结论，输出最小补证动作。
- 需要生产写入、敏感数据外发或不可逆操作：停止并请求明确授权。
