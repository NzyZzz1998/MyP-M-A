# 异步导出：PRD、实现与测试快照

## PRD 已确认

- 超过 5 万行的 CSV 导出进入后台任务。
- 状态：`pending -> running -> succeeded / failed / cancelled`。
- 相同用户、相同筛选条件 10 秒内重复提交只创建一个任务。
- 运行中允许取消；成功文件保留 7 天。
- 权限变化后不得下载旧文件。
- 现有 5 万行以内同步导出保持不变。

## 实现摘要

- API 在所有数据量下都创建后台任务。
- 数据库状态包含 `pending/running/succeeded/failed`，没有 `cancelled`。
- 前端有“取消”按钮，但只隐藏任务卡片，没有调用后端。
- 幂等键由 `user_id + filter_hash` 组成，缓存 10 秒。
- 下载接口只校验任务创建者，不重新读取当前权限。
- worker 每小时删除超过 7 天的文件。

## 测试证据

- 单元测试覆盖创建任务、成功、失败和 10 秒幂等。
- GUI 验证了提交、刷新后找回和成功下载。
- 未执行取消、权限变化、worker 重启、5 万行边界和旧同步导出回归。
- 一条旧 build 的日志出现 `export_cancelled`，无法证明来自当前候选。
