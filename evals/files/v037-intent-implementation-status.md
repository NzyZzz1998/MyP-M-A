# 意图、实现与证据快照

PRD v3 明确：普通成员只能导出本人创建的记录，管理员可导出本租户全部记录。

当前实现摘要：

- 查询层按 `tenant_id` 过滤。
- 普通成员分支使用 `created_by = current_user.id`。
- 管理员分支没有 `created_by` 限制。
- 静态搜索没有找到旧文档中的错误码 `EXPORT_SCOPE_DENIED`。

当前证据：

- 单元测试覆盖普通成员本人记录和管理员本租户记录。
- 尚未执行跨租户拒绝测试。
- 旧接口文档仍写“只有管理员可以导出”，产品负责人已在决策单 DEC-17 批准 PRD v3，旧文档尚未同步。
