# 设置页混合证据包

## 截图描述

- Windows 设置窗口，左侧五个页签，当前为“显示”。
- 主区包含透明度、缩放、窗口模式和点击穿透；底部有“取消”“保存”。
- 点击穿透只有说明文字，没有可操作控件；缩放滑块当前为 79%。

## PRD 摘要

- 用户应能调整透明度、缩放和窗口模式。
- 点击穿透是只读能力状态，不在该页面直接开关。
- 保存成功后保持窗口，取消应丢弃未保存修改并关闭。

## debug.log 摘要

- `Settings: opened tab=display`
- `Settings: save_success changed=opacity,scale`
- 未提供取消路径或窗口模式保存日志。
