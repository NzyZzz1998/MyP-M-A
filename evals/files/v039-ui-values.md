# v0.39 UI 值语义夹具

设置页包含“月薪”输入框：

- 首次默认值：`800`
- 打开页面时最后已保存值：`1000`
- 用户本轮输入值：`1300`
- 保存成功：持久化 `1300`，此后最后已保存值为 `1300`
- 保存失败：输入框仍显示 `1300` 供用户修正，但持久化值保持 `1000`
- 无变化保存：当前输入等于最后已保存值，不写配置并提示“没有需要保存的更改”
- 取消或关闭：放弃未保存输入，恢复显示最后已保存值
- 重置默认：只把当前输入改成 `800`；用户再次保存后才持久化
- 重启：读取最后成功保存的值，不读取上次失败或取消的输入

请把这组行为写进正式 PRD，不要只写“失败时保留当前值”。
